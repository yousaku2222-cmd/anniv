## Google Play（日本語）

### 簡単な説明（最大80文字）
> 誕生日や記念日を登録して、当日と数日前にお知らせ。ウィジェットで残り日数がひと目で。

### 詳しい説明（最大4000文字）
```
Anniv（アニヴ）は、誕生日・記念日・イベントまでの日数を数えるシンプルなアプリです。

■ 大切な日を、忘れない
登録した日の当日と、7日前・3日前・1日前にプッシュ通知でお知らせします。通知の時刻はまとめて設定でき、記念日ごとに変更もできます。

■ ホーム画面ウィジェット
次に来る記念日までの残り日数を、ホーム画面のウィジェットでいつでも確認できます。

■ テンプレートですぐ登録
「誕生日」「記念日」「試験」「旅行」などのテンプレートを選ぶだけで、アイコン・繰り返し・通知がまとめて設定されます。数タップで完了します。

■ カウントの向きを選べる
・あと何日（カウントダウン）
・経過日数（付き合って◯日、など）
毎年・毎月・毎週の繰り返しにも対応。100日・1年などの節目も自動でお知らせします。

■ グループで整理
「家族」「仕事」などのグループに分けて、並び順も自由に変えられます。

■ データは端末内に保存
登録した内容は端末の中だけに保存されます。アカウント登録は不要です。バックアップは「書き出す」機能でいつでも取り出せます。

■ 広告について
無料でご利用いただけます。画面下部に控えめなバナー広告が表示されます。買い切りの「広告を非表示にする」で、いつでも広告なしにできます。
```

### このバージョンの新機能（リリースノート）
```
・最初のリリースです。誕生日・記念日のカウントダウン、通知、ホーム画面ウィジェット、バックアップに対応しました。
```

## 掲載画像（docs/store-assets/）

| ファイル | 用途 |
|---|---|
| `feature-graphic-1024x500.png` | Google Play フィーチャーグラフィック（1024×500、生成済み） |
| `screenshot-1-home.png` 〜 `screenshot-4-settings.png` | 実機（800×1280）で撮影した参考スクショ（ホーム / 詳細 / 作成 / 設定） |

再撮影の指針:
- Play は最低2枚、推奨 4〜8枚。1080×1920 以上の端末で撮り直すと綺麗
- App Store は 6.7"（1290×2796）と 6.5" 用が必要。iPhone シミュレータで撮影
- 1枚目にキャッチコピー（例「大切な日まで、あと何日」）を重ねると訴求力が上がる
- 参考スクショはサンプルデータ（母の誕生日 / 沖縄旅行 など）と広告なし状態で撮影済み
